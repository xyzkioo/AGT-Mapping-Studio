# AGT Map Studio 修改说明

修改日期：2026-10-06  
对象：AGT Map Studio 二维地图编辑、保存及工作流状态管理  
工作仓库：`/home/xyzkioo/ros2_workspace/src/agt-lio-pgo-mapping`

## 一、修改背景

原有 Studio 将二维编辑与点云处理、地图包发布共用一套工作流。实际使用出现以下问题：

- 单独打开二维地图后，可以画框，但会话和第 4 步保存要求先打开 PCD。
- 固定组合算法没有读取通用转换器参数，参数修改却会使地图变成 STALE，保存和重新生成互相阻塞。
- 参数回填触发修改信号，可能在回填尚未完成时覆盖会话中的其他参数。
- 切换地图或退出时，未保存修改的保护不完整。
- 会话未恢复二维编辑历史；只画禁行区时，工作流可能认为没有修改。
- 导出目录固定，重复导出存在覆盖风险，多文件写入失败缺少整体保护。

本次修改优先让二维编辑能够独立完成“打开、修改、保存、重新打开”，并修正相关流程状态。

## 二、具体修改

### 1. 独立二维保存

新增菜单“Save 2D Map”和“Save 2D Map As”，快捷键分别为 **Ctrl+S**、**Ctrl+Shift+S**。

只需要打开 `map.yaml` 及其引用的 PGM，即可编辑和保存，不要求加载 PCD，也不依赖点云转换、重定位或发布工具。首次保存选择父目录，程序创建 `edited_map_<时间>`；后续保存更新这个编辑目录。

二维修改仍只作用于栅格地图，不会自动修改三维 PCD。

### 2. 参数与算法对齐

固定组合流程显示并锁定实际使用的参数：0.1 米栅格、1 米边界、每格最低点数 2、0.22 米台阶阈值、20° 坡度阈值。当前输出使用几何栅格结果，历史路线直接清障选项不参与该结果。

通用转换器参数仍用于相应的通用转换路径。固定流程的状态检查不再因为未使用的通用参数变化而误判过期，同时仍检查输入点云标识和栅格文件是否一致。参数和发布目标回填期间阻断控件修改信号，避免数值串改。

上述数值为已有实验配置，不是车辆安全限值或标准要求。

### 3. 第 4 步保存与重算保护

固定组合结果的二维修改可以直接导出，无需调用缺失的外部补丁工具。只画禁行区也计入需要处理的二维编辑。

已保存的编辑历史不再直接阻止重新运行组合处理；未保存编辑仍要求先保存。处理期间如二维编辑发生变化，回调保留当前视图，不用新结果覆盖它。

### 4. 未保存编辑保护

切换点云、切换二维地图或退出前，检查未保存编辑，提供保存、放弃、取消选项。取消操作或保存失败时，不继续切换或退出。

打开新的 PCD 时清空旧二维地图及其编辑状态，避免新点云与旧栅格混用。

### 5. 保存与恢复编辑记录

保存地图时同时输出编辑历史和禁行区。重新打开配套的输出 `map.yaml` 时，恢复编辑记录、禁行区以及撤销/重做栈。

编辑记录增加地图尺寸、分辨率、原点信息及撤销/重做操作 ID。读取时检查几何信息和像素范围；不匹配的记录不会直接套到当前地图上。编辑状态指纹加入实际坐标和像素修改值，减少不同编辑被误认为相同状态的问题。

点云会话增加 `editor_map_yaml` 字段，记录已保存的二维输出位置。恢复会话时读取相应输出及其编辑记录。旧会话未包含该字段时继续使用原导航输出位置；无法从未持久化的旧会话中凭空恢复丢失的编辑。

### 6. 输出文件保护

地图文件先写入临时目录，完成后再替换输出目录；替换失败尝试回退原目录。原有普通预览导出入口在覆盖已有地图前增加确认。

该机制保护正常写入失败，不等同于已经验证断电或磁盘故障下的完整恢复能力。

### 7. 工具与格式提示

缺少外部转换、补丁、重定位或发布工具时，相应工作流按钮禁用并显示原因。此次没有安装这些外部工具，不能视为完整地图包发布流程已经可用。

二维读取目前支持 PGM、trinary 模式和零原点旋转角。对其他地图模式或非零原点旋转明确拒绝，避免静默按错误规则解释地图；此次没有新增 PNG、旋转地图或其他模式支持。

### 8. 文件选择窗口输入响应

针对用户反馈选文件时滚轮和方向键均无效，将打开文件、保存文件、选择目录的入口统一改用 Qt 自带的非系统文件窗口。窗口默认采用详细列表，并在首次显示时把输入焦点置于文件列表，支持方向键、翻页键和滚轮浏览；关闭目录自定义图标查询，以减少不必要的目录图标开销。

实现位置为 `apps/agt_map_studio/src/ui/StudioFileDialog.hpp`。使用 160 个临时文件的 Qt offscreen 回归测试验证了列表焦点、向下键、Page Down、滚轮滚动和文件选择；`test_file_dialog_navigation` 与独立二维流程回归通过。用户桌面端原始失去响应的具体原因尚未确认，此修改先绕开系统文件弹窗，并不等于已完成桌面环境根因分析。

## 三、保存结果

| 文件 | 内容 |
|---|---|
| `map.pgm` | 编辑后的二维栅格像素 |
| `map.yaml` | 图像路径、分辨率、原点及占据阈值 |
| `map_refinement.yaml` | 编辑操作、禁行区记录、撤销/重做栈 |
| `keepout_zones.yaml` | 独立禁行区数据 |
| `metadata.yaml` | 导出地图及编辑数量等信息 |

禁行区不会自动改黑栅格。导航端需要显式接入禁行区数据，文件存在不代表车辆已经执行禁行约束。

## 六、使用新版的注意事项

本地可执行文件已重新编译，启动脚本 `scripts/map_studio.sh` 使用仓库 `.studio-install` 中的版本。已经运行的旧窗口不会自动更新，需要先保存当前修改，再重启。

新版独立二维编辑的保存入口是 **File → Save 2D Map**，也可直接按 **Ctrl+S**；不需要先运行第 3 步生成地图。
