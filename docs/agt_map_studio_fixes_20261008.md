# AGT Map Studio 第一批修复 · 2026-10-08

本批处理审查报告中的 F01–F05，并修复与状态一致性直接相关的 F11。实现位于实际运行仓库 `agt-lio-pgo-mapping`；正式地图、算法参数、已有 visibility 工作未改动。

## 已完成

- **F01 会话持久化**：统一显式保存、退出保存和工作流保存入口。三维编辑使用独立 YAML sidecar 保存精确点编号、完整历史、当前选择、几何、撤销/重做栈和显示标志。sidecar 和会话描述分别原子写入，描述提交成功后才清理旧 sidecar。恢复前验证源 PCD 摘要、点数、命令编号、索引和栈结构，以及二维地图/历史；拒绝错误数据时保留当前编辑。恢复复用已加载的点云，避免重复读取大 PCD。
- **F02 删除输出一致性**：Studio 导出 `remove_indices`，编号通过 `LoadedPointCloud.source_indices` 映射到原始 PCD 行，绑定源文件 SHA256 和原始点数。反选、屏幕选区及重复坐标不会被包围盒扩大。Python 精炼后端在过滤前验证来源，使用集合查询编号；保留原有几何规则兼容性。加载后源文件改变时拒绝导出。坐标式消费者遇到精确编号规则明确报错，避免静默漏删。
- **F03 撤销几何**：恢复删除前的选择几何；去重选中编号，避免同一点进入命令多次。撤销后再次删除仍保留原来的球形/多边形等证据。
- **F04 异步输入保护**：通用外部工具启动时记录源路径与文件属性、实时三维/二维编辑指纹、转换参数、发布目标和工作流依赖快照。完成时若输入变化，停止队列并提示重新执行，保留工具输出和当前编辑，不把结果标为最新。此保护偏保守：修改任意快照字段会拒绝该次结果，包括部分与当前任务无关的参数修改。
- **F05 二维保存语义**：导出统一使用 trinary、negate=0、occupied_thresh=0.65、free_thresh=0.196 和灰度 0/254/205。提交输出目录前重读导出地图并逐格比对，保证占用/空闲/未知不因原始 negate 或阈值而改变。
- **F11 指纹完整性**：指纹来自完整规则几何和精确编辑编号，覆盖球心、多边形顶点及相同点数下不同删除集合；撤销操作不进入活动指纹。
- **退出保护**：撤销全部已保存删除仍被识别为未保存；选择“丢弃”退出时不再自动覆盖已保存会话。

## 兼容性

旧会话若带有三维删除指纹但没有精确编辑记录，恢复会明确拒绝，提示从已有精炼 PCD 继续。旧文件不包含原始点编号，无法可靠推算当时的离散选择。无三维编辑的旧会话继续支持。

新精确规则要求更新后的 `agt_map_refinement_core`。已将该包以 symlink-install 构建进本仓库 `.studio-install`，启动脚本会加载此 overlay。跨环境使用时需同步更新 Studio 与该后端。SHA256 绑定仅用于手工编辑规则和会话，未改变注册算法的输入协议。
